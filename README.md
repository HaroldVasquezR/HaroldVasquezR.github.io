# Harold Vásquez — Professional Website

Professional website of Harold Vásquez, Ph.D., economist specializing in macroeconomics, international finance, applied economic research, and computational modeling.

**Website:** https://haroldvasquezr.github.io/

## Website Sections

- **Home:** Professional profile, expertise, and areas of interest.
- **Teaching:** Macroeconomics courses, computational models, and educational resources.
- **Projects:** Applied economic research, financial data infrastructure, and technology-driven projects.
- **Research:** Journal articles, books, book chapters, working papers, and institutional publications.

## Technologies

The website is developed using HTML and CSS and published through GitHub Pages.
